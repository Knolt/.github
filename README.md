# Knolt `.github`

Organization-wide files for [Knolt](https://github.com/Knolt).

| Path | What it does |
| :-- | :-- |
| `profile/README.md` | The public page at [github.com/Knolt](https://github.com/Knolt) |
| `ISSUE_TEMPLATE/` | Bug and feature forms for every Knolt repository that has none of its own |
| `PULL_REQUEST_TEMPLATE.md` | The default pull request checklist |
| `CONTRIBUTING.md` | How the team plans, branches and reviews |
| `SECURITY.md` | How to report a vulnerability |
| `assets/` | The Knolt logo as SVG and the 512 px avatar as PNG |

A repository's own copy of any of these files replaces the default here. This repository must stay public for GitHub to apply the defaults.
